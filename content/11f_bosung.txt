# 11-I-3#7
h Đọc giá trị tại x = 0 và chu kì trên đồ thị rồi đối chiếu từng hàm.
y y = A cos x có tập giá trị [−|A|; |A|], chu kì 2π.
y Tại x = 0: 2cos 0 = 2, cos 0 = 1, 2sin 0 = 0, −2cos 0 = −2.
b Đồ thị qua (0; 2), giá trị lớn nhất 2, nhỏ nhất −2 nên loại y = cos 2x, y = 2sin x, y = −2cos x.

b Đáp án: y = 2cos x
